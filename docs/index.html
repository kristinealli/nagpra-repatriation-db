About the project

Designed around a real administrative workflow.

The original project was created for database-management and programming coursework to explore how a structured information system could support repatriation work. It was extended from a MySQL schema into Python desktop interfaces and is now packaged as a portfolio web demonstration.

Important: this is an educational portfolio project, not an official NAGPRA system and not a repository for culturally sensitive or operational records.
